# Dropped Model Prototypes

This directory keeps the unshipped Branch B, Branch C, and fusion/stacker work.
They document the exploration path for CLIP-style semantic features,
low-level residual forensic features, and multi-branch fusion.

These modules are not imported by `aigid.predict` and are not part of the
submitted model. They were built and tested as prototypes, but were not trained
on the final data bundle before the submission cutoff. CrossGuard therefore
ships Branch A only, rather than claiming an unmeasured ensemble gain.
